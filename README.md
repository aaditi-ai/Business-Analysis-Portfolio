Vendor Performance Data Analytics — SQL, Python, Power BI

Conducted end-to-end analysis of 10,692+ vendor-brand records using SQL, Python, and Power BI to evaluate pricing, inventory turnover, and vendor profitability
Identified 198 low-sales, high-margin brands for targeted pricing/promotions and flagged vendor concentration risk (top 10 vendors = 65.69% of purchases)
Found bulk purchasing cut unit costs by 72%, and flagged $2.71M in unsold inventory by identifying vendors with the lowest stock turnover
Validated profit margin differences between top and low-performing vendors via hypothesis testing and built Power BI dashboards for stakeholder reporting
